ยังไม่มีไฟล์ก็รันแอปได้ตามปกติ — ระบบจะโชว์อีโมจิเดิมแทนไปก่อนโดยอัตโนมัติ

ไม่ต้องแก้โค้ดเพิ่ม

หมายเหตุ:
- แนะนำรูปสี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใสหรือขาว จะเข้ากับดีไซน์ตู้ที่สุด
- ขนาดแนะนำ ~200x200px ขึ้นไปก็พอ ไม่ต้องใหญ่มาก
- หลังเพิ่ม/ลบ/เปลี่ยนชื่อไฟล์ในโฟลเดอร์นี้ ต้องปิดแอปแล้วรัน `flutter run -d chrome`
  ใหม่ทั้งหมด (ไม่ใช่แค่ hot reload หรือ hot restart) เพราะ asset manifest
